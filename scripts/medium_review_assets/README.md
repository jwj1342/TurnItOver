# 离线审核

直接用浏览器打开 review.html。请填写本人审核者标识并点击“开始／载入本人审核”，先观察实际三态运动，再比较参考与候选，选择判断并填写具体依据。所有案例均使用无来源含义的审核 ID；本包不含答案、来源 ID、历史判断或与来源案例的对应表。

页面按审核包和审核者标识在当前浏览器本地保存输入。重新打开页面后请再次填写同一标识并点击载入；不会自动显示其他审核者的填写。标识不构成身份认证。部分浏览器对离线存储有限制，请及时使用“导出本页审核 JSONL”备份。导出后将文件单独交回协调者，保留原始回件，不放回本审核包。空白项、无法判断以及浏览器测试夹具均不代表人审通过。若需比较独立审核者的结果，请各自完成并交回后再讨论。

blank_return.jsonl 只是原始空白模板。原生图片在本包中仅重命名，未改变像素。播放按 rest → mid → limit → mid 切换三个实际渲染状态，未生成插值图像。协调者可使用对应代码版本的 validate_review_bundle 检查本包；完整候选包含答案，不应作为独立审核输入。
